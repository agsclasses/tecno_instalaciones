# Instalaciones en viviendas · Actividades interactivas (4º ESO)

Dos actividades en HTML autocontenido (sin librerías ni conexiones externas):

- `cuadro-electrico.html`: qué aparato del cuadro salta en cada situación, laboratorio de consumo y reto de las vacaciones.
- `clasifica-y-ordena.html`: clasificar elementos por instalación y ordenar recorridos (electricidad, agua, desagüe y gas).
- `index.html`: portada con enlaces a ambas.

## Publicar en GitHub Pages
1. Crea un repositorio y sube estos tres archivos a la raíz.
2. Settings → Pages → Source: «Deploy from a branch», rama `main`, carpeta `/ (root)`.
3. La web quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
